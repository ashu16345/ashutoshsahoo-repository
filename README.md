# Ashutosh Sahoo — Portfolio Website

A responsive personal portfolio website introducing Ashutosh Sahoo, an aspiring AI & IoT Engineer.

## Files
- `index.html` — page structure and content
- `style.css` — responsive dark-theme styling
- `script.js` — mobile navigation and footer year

## Run locally
Open `index.html` in a browser, or use the Live Server extension in VS Code.

## Before publishing
1. Replace the generic GitHub and LinkedIn links with your real profile/project URLs.
2. Verify the project descriptions and list only implemented features.
3. Consider whether you want your phone number publicly displayed. You can remove it and use email instead.
4. Add your resume PDF if you want a resume download button.

## Publish
Upload the files to a GitHub repository and enable GitHub Pages in Settings → Pages.
